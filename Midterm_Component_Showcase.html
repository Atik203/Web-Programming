Every section below is a real, interactive component built with the exact HTML structure and CSS from your cheat sheet. Hover, focus, and click to see how they behave. Use Show code under any component to view the source. The left nav filters and jumps to each component. No JavaScript is used inside the components themselves — dropdowns use :hover, tabs use :checked radios, tooltips use :hover, and custom inputs use appearance:none.
