1. Create a JavaScript game where a user tries to guess a secret number generated by your code.         [10]
   Strategies are as follows:
   Index.html:
   Create a text filed (input type text) to take the users’ guess and a submit button, below the submit
   button there is a label field to show the feedbacks and results.
   Script.js:
       1. Generate a random secret number between 500 and 5000.
       2. Take the user's guess from the input field in the HTML file.
       3. Inside a function:
              a) Compare the user's guess to the secret number.
              b) Display "Too high!" or "Too low!" in the feedback area of your web page.
              c) If the guess is correct, display "Correct!" and optionally disable the input field to
                  prevent further guesses.
              d) Keep track of the number of guesses the user has made.
              e) If the user runs out of guesses (after 5 attempts), display "Out of guesses!" and
                  optionally disable the input field.
