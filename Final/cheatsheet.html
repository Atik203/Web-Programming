2. Random Integer & Range Formula Must Know
Formula for random int between min and max (inclusive):
let n = Math.floor(Math.random() * (max - min + 1)) + min;
Exam RangeExact JavaScript Code
500 to 5000 (Final 243)Math.floor(Math.random() * 4501) + 500
200 to 400 (Sample Quiz)Math.floor(Math.random() * 201) + 200
50 to 150 (Mock Quiz)Math.floor(Math.random() * 101) + 50
1 to 6 (Dice)Math.floor(Math.random() * 6) + 1
Why +1? 5000 - 500 = 4500. Without +1, 5000 will NEVER be generated (loss of marks)!

17. The 4 Must-Know SQL Queries Q3 Tasks
Every Q3 is composed of these exact 4 query patterns:
Pattern 1 — Aggregation with HAVING & ORDER BY:
SELECT Category, COUNT(*) AS SpotCount, AVG(Rating) AS AvgRate
FROM tourist_spot
GROUP BY Category
HAVING AVG(Rating) > 4.4
ORDER BY AvgRate DESC;
Pattern 2 — Guarded Arithmetic UPDATE:
-- Increase fee by 10% only if final fee <= 50
UPDATE book_loans
SET PenaltyFee = PenaltyFee * 1.10
WHERE PenaltyFee > 20.00 AND PenaltyFee * 1.10 <= 50.00;

-- Conditional grade upgrade
UPDATE student_final
SET LetterGrade = 'C'
WHERE Grade < 75 AND LetterGrade <> 'D';
Pattern 3 — Multi-Condition Filter (OR, LIKE, BETWEEN):
SELECT SpotName, Region, Rating
FROM tourist_spot
WHERE Rating > 4.5 OR SpotName LIKE '%Beach%'
ORDER BY Rating DESC;
Pattern 4 — Computed Net Worth / Revenue:
-- Total Net Worth across entire bookshop (Final 261-B)
SELECT SUM(Price * Stock) AS TotalNetWorth FROM book_info;

-- Revenue per Region with HAVING filter (Final 261-A)
SELECT Region, SUM(EntryFee * VisitorsPerYear) AS Revenue
FROM tourist_spot
GROUP BY Region
HAVING Revenue > 1000000
ORDER BY Revenue DESC;
