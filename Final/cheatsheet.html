21. Deep SQL Query Patterns Weak Point Focus
Pattern 1 — Selective Filters (OR, LIKE, BETWEEN, IN):
SELECT title, category, rating FROM records
WHERE rating > 4.5 OR title LIKE '%Beach%'
ORDER BY rating DESC;

SELECT * FROM records
WHERE rating BETWEEN 4.0 AND 4.5; -- Inclusive!

SELECT * FROM records WHERE category IN ('CSE', 'EEE');
Pattern 2 — Group Aggregations with HAVING:
-- HAVING filters aggregated groups (WHERE cannot!)
SELECT category, COUNT(*) AS total_items, AVG(rating) AS avg_rate
FROM records
GROUP BY category
HAVING COUNT(*) > 1 AND AVG(rating) > 4.4
ORDER BY avg_rate DESC;
Golden Rule: Every non-aggregated selected column MUST be in GROUP BY! Use HAVING for aggregate conditions, never WHERE!
Pattern 3 — Guarded Conditional UPDATE:
-- Arithmetic update with ceiling guard (prevent overshoot)
UPDATE records
SET fee = fee * 1.10
WHERE fee > 20.00 AND fee * 1.10 <= 50.00;

-- Conditional grade swap with exclusion
UPDATE records
SET status = 'Grace Period', fee = 0
WHERE status = 'Overdue' AND days_overdue < 7;
