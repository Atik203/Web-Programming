10. 90-Minute Exam Time Attack Guide Speed Plan
Target: 40 min per Question + 10 min Buffer:
• 0–3 min: Check if Layout is Sidebar, 2-Col Split, or Grid. Write clean semantic HTML.
• 3–8 min: Add * { margin:0; box-sizing:border-box; }, set main flex containers & background colors.
• 8–25 min: Fill inner elements: cards, inputs, buttons, tables, text content.
• 25–35 min: Apply exact arrow hex colors, borders, shadows & border-radius.
• 35–40 min: Sanity test alignment, padding, and font-weights!
